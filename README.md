# Gorf for PC (Breadbin-6502)

Play the 1983 Commodore 64 cartridge of **Gorf** like a native PC game: start it,
pick your cartridge dump once, play. It runs on
Breadbin-6502 (`external/breadbin-6502`), a small C64 launcher with an embedded
emulator, built here with a Gorf game pack: Gorf's window title and icon, its
controls ready to go, and a check that your dump is a known good one.

**The game itself is not included.** You need your own dump of the Gorf cartridge
(`.crt` or raw `.bin`). It's only ever read, never copied, changed or uploaded.

## Playing

1. Start `gorf`.
2. Click **Select ROM…** (or drag your `.crt` onto the window) and pick your dump.
3. Play. Next time, the game starts straight away.

| Key | Action |
|---|---|
| Arrow keys | move |
| Space or Left Ctrl | fire (press it on the title screen to start) |
| Esc | pause and open the menu (video, audio, controls, ROM) |
| F11 | fullscreen |

Controls can be changed in the menu's **Input** tab. Gorf uses joystick port 1,
which is set for you.

Known good dump:

| File | SHA-1 of the ROM data |
|---|---|
| `Gorf (USA, Europe).crt` (16K cartridge) | `4d24d5ed3d8b38235d9ae5965b675ffece0981cc` |

Other dumps can still be played. The launcher warns you first.

Settings are stored in `~/.config/breadbin-6502/games/gorf/` (Linux/BSD),
`%APPDATA%\breadbin-6502\games\gorf\` (Windows) or
`~/Library/Application Support/breadbin-6502/games/gorf/` (macOS).

## Building

```sh
git clone --recursive <this repo>
cd gorf-port
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build      # checks the game pack, no ROM needed
./build/gorf
```

If you cloned without `--recursive`, run `git submodule update --init --recursive`.
Build requirements are the launcher's (see `external/breadbin-6502/README.md`): CMake ≥ 3.20,
a C11/C++17 compiler, and on Linux the X11, OpenGL, PulseAudio and D-Bus development
packages.

## Layout

```
gamepacks/gorf/     game pack: game.toml, icon.png, banner.png (built into the executable)
external/breadbin-6502/   the launcher, a git submodule pinned to a release tag
tools/make_art.py   generates icon.png and banner.png (original, procedural art)
tests/              game pack checks
```

The launcher version is pinned on purpose: updating it is a deliberate step
(`git -C external/breadbin-6502 checkout vX.Y.Z`, test, commit). The build refuses a
launcher older than `min_launcher_version` in `game.toml`.
